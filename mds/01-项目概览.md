# 项目概览

## 项目简介

**exam-system** 是一个基于 Next.js 16 的在线考试系统，用于 **AI Coding Workshop 结业考试**。系统分为考生端（前台答题）和管理端（后台阅卷/统计）两部分。

- **项目名称**：exam-platform
- **版本**：0.1.0
- **性质**：Workshop 培训实验项目（学员在已有架构上补完部分管理后台功能）

## 核心功能

| 功能 | 说明 | 状态 |
|------|------|------|
| 考生注册/进入 | 输入姓名开始考试，防重复提交 | ✅ 已完成 |
| 在线答题 | 单选、多选、判断、简答、场景分析 5 种题型 | ✅ 已完成 |
| 自动保存 | 切题时自动保存答案到后端 | ✅ 已完成 |
| 倒计时 | 20 分钟考试限时，到时自动提交 | ✅ 已完成 |
| AI 评分 | 客观题即时评分 + 主观题 LLM 评分（/mock 双模式） | ✅ 已完成 |
| 成绩展示 | 考生端实时轮询评分状态，完成后展示分数和分项 | ✅ 已完成 |
| 管理员登录 | HMAC-SHA256 cookie 鉴权 | ✅ 已完成 |
| 成绩总览 | 管理后台查看所有考生成绩、统计指标 | ✅ 已完成 |
| CSV 导出 | 导出成绩为 CSV 文件 | ✅ 已完成 |
| 数据清空 | 管理员可清空所有考试数据 | ✅ 已完成 |
| 重评计分 | 按新分值重算已有成绩（rescore） | ✅ 已完成 |
| 缺答补分 | 对因网络丢失的客观题答案给满分 | ✅ 已完成 |
| 答卷详情页 | 管理员查看每份答卷的逐题详情 | ❌ 待实现 (Task 1) |
| 重评失败题 | 重新评分 AI 评分失败的主观题 | ❌ 待实现 (Task 2) |
| 题型正确率统计 | 统计每道客观题的正确率 | ❌ 待实现 (Task 3) |

## 技术栈

| 层级 | 技术 | 版本 |

| 框架 | Next.js (App Router) | 16.2.3 |
| 前端 | React | 19.2.4 |
| 语言 | TypeScript (strict mode) | ^5 |
| 样式 | Tailwind CSS v4 | ^4 |
| AI SDK | @anthropic-ai/sdk | ^0.88.0 |
| ID 生成 | nanoid | ^5.1.7 |
| 包管理 | pnpm | - |

## 环境变量

所有环境变量均为**可选**，有默认 fallback：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `ANTHROPIC_API_KEY` | LLM 评分 API Key | 空（走 mock 评分） |
| `ANTHROPIC_BASE_URL` | LLM API 基地址 | `https://api.anthropic.com` |
| `ADMIN_PASSWORD` | 管理员密码 | `workshop2026` |

## 常用命令

```bash
pnpm install          # 安装依赖
pnpm dev              # 启动开发服务器 (http://localhost:3000)
npx tsc --noEmit      # 类型检查
pnpm lint             # ESLint 检查
pnpm build            # 生产构建
```

**Node 版本要求**：≥ 20
